# Profiles Contribution Guide

Welcome to the Profiles directory! This guide will help new contributors create issues, submit pull requests (PRs), and get involved.

## 🚀 Step-by-Step Guide

1. **Create an Issue First**
   Before working on a profile, create an issue in this repository. Fill out all the required information.
2. **Assign the Issue to Yourself**
   Comment on the issue asking to be assigned.
3. **Fork the Repository**
   If you haven't already, fork this repository to your own GitHub account.
4. **Make Changes and Commit**
   Add your profile to the `Profiles` directory. Once satisfied, commit them.
5. **Submit a Pull Request (PR)**
   Open a PR from your fork to the upstream repository.
6. **Link the PR to the Issue**
   In your PR description, mention the issue number (e.g., "Fixes #12").
7. **Assign Reviewers & Wait**
   Request a review from the maintainers. Be patient and respond to feedback.

## 💡 Tips for New Contributors
- Don't be afraid to ask questions in the issues or discussions.
- Happy contributing! 🎉
